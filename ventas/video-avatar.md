# Paquete para videos con avatar

## Recomendacion practica

Usa **HeyGen** para el primer video comercial. Es de los mas sencillos para ventas: pegas guion, eliges avatar, eliges voz en espanol latino y subes capturas como apoyo visual.

Alternativas:

- **Synthesia**: mas corporativo, buena calidad para capacitacion y demos formales.
- **D-ID**: util si quieres animar una foto/avatar propio y hacer piezas cortas.

## Video 1: anuncio corto, 45 segundos

Objetivo: captar interes y mandar por WhatsApp, Facebook o LinkedIn.

Guion:

```text
Hola, soy Emma Presupuestos Pro.

Si haces presupuestos de obra en Excel, sabes cuanto tiempo se va en buscar conceptos, copiar precios, calcular indirectos y preparar una salida para el cliente.

Emma te ayuda a crear presupuestos mas rapido con una base de 6,185 conceptos, partidas de obra, calculo de indirectos, utilidad, imprevistos, FASAR, insumos, analisis de precios unitarios, Excel e impresion profesional.

La idea es simple: menos captura repetitiva, mas control de tus numeros y una presentacion mas clara para vender la obra.

Agenda una demo de cinco minutos y ve como se arma un presupuesto completo.
```

## Video 2: demo guiada, 90 segundos

Objetivo: explicar el flujo antes de una llamada.

Guion:

```text
Te muestro rapidamente como funciona Emma Presupuestos Pro.

Primero capturas los datos de empresa, cliente, obra y ubicacion. Esto ayuda a que la propuesta salga lista para presentarse.

Despues agregas conceptos desde la base de precios. Emma trabaja con partidas de obra y una base de 6,185 conceptos, cada uno con unidad, precio unitario, materiales y mano de obra.

Al capturar cantidades, el sistema calcula el importe de cada concepto y el costo directo del presupuesto.

Luego puedes revisar indirectos, imprevistos, utilidad y el total general en pesos mexicanos. Tambien tienes modulo de FASAR para mano de obra y listado acumulado de insumos.

Al final, puedes exportar Excel, generar desgloses, preparar analisis de precios unitarios o imprimir una salida profesional para el cliente.

Emma no reemplaza tu criterio como constructor. Te da estructura, velocidad y una forma mas clara de defender tus precios.
```

## Configuracion sugerida en la plataforma

- Formato: horizontal 16:9 para demo y landing.
- Version extra: vertical 9:16 para WhatsApp, Reels y TikTok.
- Voz: espanol latino, tono profesional y cercano.
- Avatar: presentador/a de oficina, ropa formal sencilla, fondo neutro.
- Ritmo: natural, no demasiado rapido.
- Subtitulos: activados.
- Logo: usa "Emma Presupuestos Pro" como texto de marca.

## Flujo para producir

1. Entra a HeyGen, Synthesia o D-ID.
2. Crea proyecto nuevo.
3. Pega el guion del video.
4. Elige avatar y voz en espanol latino.
5. Sube las capturas de `assets/screenshots`.
6. Coloca capturas como slides o elementos visuales.
7. Genera preview.
8. Exporta MP4.
9. Guarda los videos en `assets/videos`.
